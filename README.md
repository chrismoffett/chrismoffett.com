# chrismoffett.com

One-page personal site, plain HTML and CSS, published with GitHub Pages. Edit `index.html`; changes on `main` go live automatically.

The `CNAME` file holds the custom domain (chrismoffett.com). DNS lives at EuroVPS: four apex A records to GitHub Pages, `www` as a CNAME to `chrismoffett.github.io`. Email records (Google Workspace, MailerLite) are separate and must not be touched.
